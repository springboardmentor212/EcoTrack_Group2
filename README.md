# EcoTrack 🌱

**Track Your Impact. Build a Greener Future.**

EcoTrack is a sustainability-focused web application that helps users track everyday activities, monitor their environmental impact, and work towards more sustainable habits.

The platform brings activity tracking, sustainability goals, community challenges, notifications, and administrative tools together in one place.

## ✨ Features

### User Features
- **Activity Tracking:** Track transportation, electricity consumption, and waste management.
- **Carbon Footprint Monitoring:** Record activities and review environmental impact data.
- **Sustainability Goals:** Set goals and monitor progress.
- **Community Challenges:** Participate in sustainability-focused challenges.
- **Notifications & Reminders:** Receive notifications and scheduled reminders.
- **Profile & Settings:** Manage account information and preferences.
- **Authentication:** User registration, login, and email verification.

### Admin Features
- **Admin Dashboard:** View platform statistics.
- **User Management:** Manage user accounts.
- **Challenge Management:** Manage sustainability challenges.
- **Reports:** Access user and challenge information.
- **Admin Profile & Settings:** Manage administrator information and preferences.

## 🛠️ Technology Stack

| Component | Technologies |
|---|---|
| Frontend | React.js, JavaScript, Vite |
| Styling | Tailwind CSS, CSS |
| Routing | React Router |
| API Integration | Axios |
| Backend | Node.js, Express.js |
| Database | MongoDB, Mongoose |
| Email Services | Nodemailer |
| Scheduled Tasks | node-cron |

## 🏗️ System Architecture

EcoTrack follows a client-server architecture.

1. **Frontend:** React.js provides the user interface and navigation.
2. **Backend:** Node.js and Express.js handle API requests and application logic.
3. **Database:** MongoDB stores application data, accessed through Mongoose.
4. **Supporting Services:** Email functionality, scheduled tasks, data aggregation, and report generation support application features.

## 🚀 Getting Started

### Prerequisites
- Node.js and npm
- MongoDB
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/springboardmentor212/EcoTrack_Group2.git
cd EcoTrack_Group2
```

### 2. Set Up the Frontend

```bash
cd frontend
npm install
npm run dev
```

### 3. Set Up the Backend

Open a **separate terminal** from the project root, then run:

```bash
cd backend
npm install
npm start
```
